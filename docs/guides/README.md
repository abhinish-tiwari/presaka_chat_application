## 🌟 What is Preṣaka?

**Preṣaka** (प्रेषक) is a modern, real-time messaging application built with:
- **Trust** - Secure, private communication
- **Culture** - Rooted in Indian heritage
- **Scale** - Ready for millions of users

### Key Features (MVP - Completed ✅)
- Phone number authentication with OTP
- Real-time messaging with WebSocket
- Message persistence
- Read receipts
- Typing indicators
- Online/offline presence
- User profiles
- Message deletion
- User search
- Emoji support

### Upcoming Features
See [REMAINING_FEATURES.md](../features/REMAINING_FEATURES.md) for the complete list of 51 planned features.
