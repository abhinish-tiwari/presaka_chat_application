# Product Roadmap

## Vision

Build a trusted, real-time messaging platform that starts simple and scales globally, with an India-first approach.

---

## Phase 1: MVP (Months 1-3)

**Goal:** Launch a working product with core features

### Features

#### Authentication ✅
- [x] Phone number + OTP login
- [x] JWT token management
- [x] Session handling
- [x] Token refresh mechanism

#### Messaging 🚧
- [ ] 1-to-1 real-time chat
- [ ] Message persistence
- [ ] Message history
- [ ] Offline message queue
- [ ] Automatic reconnection

#### User Management 🚧
- [ ] User profiles
- [ ] Avatar upload
- [ ] Phone number search
- [ ] Contact list

#### Presence 📋
- [ ] Online/offline status
- [ ] Last seen timestamp
- [ ] Real-time presence updates

#### UI/UX 📋
- [ ] Clean, minimal interface
- [ ] Responsive design
- [ ] Dark mode support
- [ ] Loading states
- [ ] Error handling

### Technical Goals
- [ ] PostgreSQL database setup
- [ ] Redis caching layer
- [ ] Socket.IO integration
- [ ] REST API implementation
- [ ] Basic security measures

### Success Metrics
- 100 active users
- < 500ms message delivery
- 99% uptime
- < 5% error rate
